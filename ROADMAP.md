# Roadmap

What comes after `1.0.0`. Releases ship from `main`, see [RELEASING.md](RELEASING.md), and
what each one changed is in the [changelog](CHANGELOG.md).

## Next

- **Browser extension**: change the state of the movie open on IMDb, TMDB, SensCritique or
  AlloCiné on your Sensorr.
- **Discover vote floor**: a minimum vote count by default when Discover sorts by vote average.
- **Home ranking**: rank the bounded Home rows on several pages of Discover results.
- **Size bounds**: a ceiling or a floor on the release size, per resolution, in a policy.
- **Import from Radarr**: take over the movies Radarr follows, as `migrate sonarr` does for
  Sonarr.
- **Rename and move**: file a downloaded movie into a folder and a name built from a template,
  compatible with the tools already in use for it, such as FileBot, tinyMediaManager or mnamer.
- **Unraid and Qnap**: an Unraid template and a QPKG package.
